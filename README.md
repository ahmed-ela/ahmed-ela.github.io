# Personal website

A simple public website hosted at https://ahmed-ela.github.io/.

- Edit `index.html` to replace the filler paragraph and list of links.
- Edit `styles.css` to adjust the layout.
- The profile image uses the current GitHub account avatar and appears in grayscale.
- GitHub Pages publishes the root of `main` automatically.

Everything committed to this repository is public. Keep private drafts elsewhere.
